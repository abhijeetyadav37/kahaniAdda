# Production deployment checklist
Use a GitHub-connected Python WSGI host with persistent PostgreSQL. Do not deploy SQLite on ephemeral storage. Free tiers, sleeping limits, card requirements and persistence change; check the provider's current pricing before creating resources. Build command: `pip install -r requirements.txt`. Start command: `gunicorn app:app --workers 2 --timeout 120`. Configure `DATABASE_URL` from your PostgreSQL provider, a long random `SECRET_KEY`, `SITE_URL` matching the public HTTPS URL, `COOKIE_SECURE=1`, and `FLASK_DEBUG=0`. Run `flask --app app init-db`, `flask --app app seed`, then `flask --app app create-admin` in a secure provider shell. Verify submission moderation and persistence after restart/redeploy. If the host has no shell/one-off command, choose a provider that supports secure admin initialization rather than committing credentials.
