# Optional translation provider
Original stories remain unchanged. Admin → Dashboard → Translations stores a separate manually reviewed translation. Automatic translation is not enabled. For Google Cloud Translation, create a Cloud project, enable the API, configure billing and quotas as required, and read current official pricing; don't assume unlimited free use. Use a least-privilege service identity and store credentials only as hosting environment secrets, never in Git. Add a server-side action with size limits, error handling and human review. Preserve the original and test Hindi/Hinglish idioms carefully.
