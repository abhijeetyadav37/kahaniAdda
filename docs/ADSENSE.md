# AdSense setup
Ad areas start as labeled placeholders. No live ads or IDs are included. Publish original, useful content; verify site ownership in the official AdSense account; follow its current verification instructions; wait for account/site review; then create ad units and use only the publisher and slot IDs AdSense provides. Live ad code is not injected by this starter and should be added as a deliberate, reviewed code change after approval. Do not click your own ads or encourage accidental clicks. Approval and income are not guaranteed. Revenue depends on traffic, geography, demand, viewability and compliance.
