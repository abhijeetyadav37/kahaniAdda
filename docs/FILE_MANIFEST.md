# File manifest
- `app.py`: Flask routes, SQLAlchemy models, validation, admin and CLI commands.
- `requirements.txt`: runtime dependencies.
- `.env.example`, `.gitignore`: configuration example and secret/database exclusions.
- `setup.bat`, `run.bat`: Windows setup and start helpers.
- `Procfile`: Gunicorn production start command.
- `templates/`: public, admin, partial and error pages.
- `static/css/style.css`, `static/js/site.js`: responsive styling and lightweight interactions.
- `tests/test_app.py`: core route, admin and submission workflow tests.
- `docs/`: deployment, AdSense, translation and troubleshooting notes.
